# Employee Management System

A backend application for managing employees using Spring Boot and MySQL.

## 🛠 Technologies

- Java
- Spring Boot
- Spring Data JPA
- MySQL
- Maven
- REST API


## 📋 Description

Employee Management System is a REST API application that allows you to manage employee information.

The application provides basic CRUD operations for employees:

- Create a new employee
- Get all employees
- Get an employee by ID
- Update employee information
- Delete an employee
